TIGOJ AI Pro v1
===============

Primera versión:
- Aplicación Android nativa.
- Chat con el modelo local de LLM AI Server.
- Conexión a http://127.0.0.1:11434/v1/chat/completions
- Memoria local básica del historial.
- No necesita OpenAI ni Gemini.

Para funcionar:
1. Abrir LLM AI Server.
2. Cargar el modelo.
3. Iniciar API/WebUI en el puerto 11434.
4. Abrir TIGOJ AI Pro.

Este ZIP es el proyecto fuente. Debe compilarse para producir un APK.
